# AI Hub — Investor Pitch Deck

World-class HTML pitch deck for **AI Hub** (Student AI live wedge → Health AI + Finance AI).

## Open

```bash
# from repo root
open pitch/index.html
# or
npx --yes serve pitch -p 5173
```

Then visit `http://localhost:5173`.

## Present

| Key | Action |
|-----|--------|
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `F` | Fullscreen |
| `P` | Print / Save as PDF |
| Swipe | Next / previous on touch |

Print dialog → **Landscape** → **Save as PDF** for a shareable leave-behind.
