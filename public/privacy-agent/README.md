# Privacy Agent

Live house filter under AI Hub: set rules, apply the tracker list on your phone or router, and check this network.

House rules stay in this browser. Choose **On my network**, copy the house list into AdGuard or NextDNS, then tap **Check this network**. **Off** parks the list in this app — remove it from AdGuard or NextDNS too if you already added it. **This computer** remains an advanced local DNS option.
