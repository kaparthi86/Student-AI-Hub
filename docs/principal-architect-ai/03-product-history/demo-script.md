# Demo Script — My Student Coach (8–10 minutes)

**Audience:** hiring panel / investors / design partners  
**Environment:** Chrome or Edge recommended for Voice; production HTTPS URL  
**Prep:** Signed-in test account; one PDF for Notebook; mic permission

## Act 1 — Problem (45s)

“Students don’t need another generic chatbot. They need a coach that answers first, respects honor code, and works on a phone.”

## Act 2 — Login & Home (60s)

1. Show one-screen Google gateway + disclaimer.  
2. Land on Coach Home.  
3. Point at Android-style bottom nav.

## Act 3 — Ask quality (2 min)

1. Ask a multi-step concept question in **Explain**.  
2. Show answer-first, clean steps (no `**` noise).  
3. Switch to **Guide** — show hint-only behavior.  
4. Use **Explain simply** control on last answer.  
5. Optional: Live web on → show source chips.

## Act 4 — Notebook grounding (2 min)

1. Upload class notes / PDF.  
2. Show structured analyze sections.  
3. Ask a follow-up not in the doc → “Not in document”.

## Act 5 — Voice loop (2 min)

1. Open Voice Tutor.  
2. Ask a short question; note speak-early before full text finishes.  
3. Barge in mid-answer; ask a follow-up.  
4. Show auto-continue toggle.

## Act 6 — Architecture & cost (90s)

1. HF Router + cache + voiceMode token cap.  
2. Weekly thumbs → contract fix loop.  
3. Close with roadmap: TWA Play, then realtime voice.
