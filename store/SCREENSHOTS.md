# Screenshot checklist (Play Store)

Capture on a mid-size Android phone (or Chrome device mode) with the live Soft paper UI:

1. **Landing / AI Hub** — brand-first Soft paper landing (optional if signed-in shots dominate)
2. **Hub home** — AI Hub with Student AI tile
3. **Ask hero** — “What do you want to learn today?” + branded composer
4. **Ask answer + Practice** — clean assistant reply, follow-up chips, and **Practice this topic** dock under the answer
5. **Code** — debug/learn code hero
6. **Notebook empty** — dropzone “up to 5 files”
7. **Notebook results** — study pack + follow-up bar (Practice dock if visible)

Tips:
- Use a real student prompt (not lorem ipsum)
- Hide browser chrome; prefer installed PWA or Android emulator app shell
- Show honor-code framing only if it stays calm (no clutter stickers on hero shots)
- Export PNG, portrait, at least 1080px on the short side
- Match Soft paper `#F7F6F3` — no dark-mode mockups
