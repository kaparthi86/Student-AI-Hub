# Screenshot checklist (Play Store)

Capture on a mid-size Android phone (or Chrome device mode) with Soft paper UI:

1. **Ask hero** — “What do you want to learn today?” + branded composer  
2. **Ask answer** — clean assistant reply + follow-up chips  
3. **Code** — debug/learn code hero  
4. **Notebook empty** — dropzone “up to 5 files”  
5. **Notebook results** — study pack + follow-up bar  

Tips:
- Use a real student prompt (not lorem ipsum)
- Hide browser chrome; prefer installed PWA or Android emulator app shell
- Export PNG, portrait, at least 1080px on the short side
